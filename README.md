Entry for the make.fun bounty **Worst Superpower**: one line, at most 140
characters, inventing the most useless superpower imaginable.

The program (`main.py`, Python 3, no dependencies) writes the line to
`/output/entry.txt`:

> I can silence any notification instantly, but only the ones I've already read.

78 characters, plain ASCII. Run it with `python3 main.py`.
